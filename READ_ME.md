# Eb Market Place Django Application 


### Important Commands
- python manage.py startapp name folder - Creates a module for example python manage.py startapp plugins plugins
- python manage.py startapp workspace ifrs_metrics_engine/apps/workspace .This is when we want to create a folder
- python manage.py runserver - Runs the server 
- django-admin startproject name - Creates new application project 
- python manage.py makemigrations to run migration also can use migrate S
